Reflection

Reflection on Coding in Markdown: STAR Method

Situation As part of the Project Presentation 3 assessment, I was required to build a digital portfolio using Markdown on GitHub. Prior to this task, I had no experience with Markdown and had never used it in any of my previous projects or coursework.

Task My responsibility was to learn Markdown from scratch and use it to structure and present my CV, projects, and reflections in a clear, professional format on GitHub.

Action Since Markdown was completely new to me, I took the initiative to teach myself. I watched YouTube tutorials to understand the basics and visited several websites to learn how specific syntax works such as how to create headings, bold text, bullet points, checkboxes, and links. I practised writing and editing the README file repeatedly, testing how changes rendered on GitHub until I felt comfortable with the format.

Result By the end of the process, I was able to successfully code my entire portfolio using Markdown. Although I would rate my current confidence level at about 6 out of 10, I recognise that this is a strong foundation to build on. The more I practise, the more fluent I will become. This experience taught me that self-directed learning is a skill in itself, and that being willing to search, watch, and try again is how real growth happens.
